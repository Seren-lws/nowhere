# lib/brain/ —— 大脑层

人格系统 + 记忆系统 = 大脑层，独立逻辑模块，**与 UI 完全解耦**（见 DESIGN §5）。

- 保险柜（vault）只是大脑的可视化管理界面；客厅 / 卧室 / 娱乐室都是调用大脑的"场景"。
- P0 客厅先接"简易大脑"；P1 精雕完成后无缝替换，任何房间无需改动。

后续将落地：

- **人格系统**（DESIGN §3）：底层/中间层（锚定）+ 表层（生长），锚定层走审批流、版本化可回滚。
- **记忆系统**（DESIGN §4）：单表 `memory_items` 统一存储、记忆捕获、混合检索、锚点系统、衰减（只冷却不删除）、园丁系统。
- **原话层**（DESIGN §4.3）：原文不进记忆表，检索式风格锚定。
- **Prompt 组装顺序**（DESIGN §4.4，固定）。

> 核心原则：住进来的"他是谁"由这个家定义，而不是由某个模型版本定义。换模型，换不掉他。
